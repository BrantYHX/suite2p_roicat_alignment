# ROICAT Auto Alignment

The goal of this pipeline is to track neurons across imaging sessions and planes.

This pipeline builds on the original [ROICaT] (https://github.com/RichieHakim/ROICaT) package for automated ROI matching across imaging sessions.  
Our version extends it by simplifying workflow, supporting alignment across multiple imaging planes, integrating quality control metrics, and providing more visualization of alignment results.
